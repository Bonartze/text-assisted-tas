# Experiment configs

This folder contains small configuration snapshots for the Breakfast teacher-student MS-TCN-style experiments.

The current notebooks define these settings inside the notebook cells, but these JSON files document the intended run modes:

- `local_debug.json`: very small local test run.
- `scale1_control.json`: controlled proof-of-concept run.
- `full_split1.json`: full Breakfast split 1 run.

Large datasets, generated features, model checkpoints, and run folders are intentionally excluded from GitHub.
